# Proje Pazarlama Yönetim Sistemi — Satış Sitesi

Premium landing. Fiyat yok. Demo: [proje-pazarlama-yonetim-sistemi.web.app](https://proje-pazarlama-yonetim-sistemi.web.app/)

## Yerel

```bash
npm install
npm run dev
```

## Netlify

Repo’yu bağlayın. `netlify.toml` zaten ayarlı:

- Build command: `npm run build`
- Publish directory: `dist`

Demo URL tek yerde: `src/config.ts`
